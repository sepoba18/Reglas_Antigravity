# Mi Skill de Proyecto

Procedimientos y guías específicas que Antigravity ejecutará al trabajar en este proyecto.

## Procedimientos
1. **Seguir las directrices de `GEMINI.md`**:
   - Mantener el código en Python 3.12 sin type hints.
   - Usar f-strings y docstrings en español.
2. **Protocolo de Traspaso**:
   - Al finalizar sesión o cambiar de computador, actualizar `CURRENT_TASK.md` y hacer push a la rama de trabajo.
